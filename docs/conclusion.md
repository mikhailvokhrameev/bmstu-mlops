# ДЗ 6, часть A: итоговый вывод

## Выбранный кандидат

Кандидатом выбран `all-r8-high` (run `de51a3b4`, `r=8`, `lr=3e-4`, адаптеры на всех семи
линейных слоях). В реестре `my-smollm-adapter` это версия 3 с алиасом `candidate`.
База даёт val loss 2.5915, кандидат — 2.5831. Выбор сделан по минимальному `final_val_loss`.

| Кандидат | final_val_loss | секунды | пик памяти, МБ | адаптер, МБ |
|---|---|---|---|---|
| all-r8-high | 2.5831 | 24.4 | 3806 | 12.7 |
| qv-r8-high | 2.5867 | 20.0 | 3766 | 5.1 |
| all-r8-low | 2.5886 | 24.6 | 3798 | 12.7 |
| qv-r8-low | 2.5890 | 20.0 | 3766 | 5.1 |
| qv-r4-high | 2.5892 | 20.1 | 3766 | 4.3 |
| qv-r4-low | 2.5896 | 20.4 | 3710 | 4.3 |

Цена выбора: адаптер `all-r8-high` около 12.7 МБ против 4–5 МБ у вариантов `qv`, обучение
на ~4 с дольше (24.4 против ~20 с), пик памяти выше на 40–100 МБ. Выигрыш у ближайшего
`qv-r8-high` по loss составляет 0.0036.

## Ограничения

- Бюджет обучения: 4 шага, пул train из 32 примеров, val из 8 примеров, batch 1 × accum 2.
- Разница между кандидатами по loss (соседи в рейтинге: 0.0003–0.0036; от лучшего: 0.0036–0.0065)
  может быть шумом: на val из 8 примеров доверительных интервалов нет, сид один, повторов нет.
- Отбор шёл только по val loss. Test для выбора не использовался.
- val loss не говорит о качестве ответов модели.
